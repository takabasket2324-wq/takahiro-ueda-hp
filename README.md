# TAKAHIRO UEDA | AI Consultant サイト

静的HTMLサイトです。ローカルでプレビューしながら編集できる環境を用意しています。

## 編集のはじめ方

### 1. 初回だけ（依存パッケージの準備）

```bash
npm install
```

### 2. プレビューを起動

```bash
npm run dev
```

ブラウザで `http://localhost:5500` が自動で開きます。
HTMLやCSSを保存すると、**自動でブラウザが更新**されます（ライブリロード）。

止めるときはターミナルで `Ctrl + C`。

## どこを編集する？

| 編集したい内容 | ファイル |
| --- | --- |
| トップページ（縦長1枚：数字・進め方・やらないこと・note・つくっている人） | `index.html` |
| プロフィール | `profile.html` |
| お問い合わせ（LINE・メール・X・フォーム） | `contact.html` |
| 旧ページ（トップへ自動で移る案内だけ。古いリンク対策で残している） | `services.html`・`flow.html` |
| 見た目・色・レイアウト | `css/style.css` |
| 動き（メニュー・数字の数えあがり・3段の図・スクロールで出る動き） | `js/main.js`（数字の図の見た目は `css/style.css` の最後「2026-10-24」の段） |

文章を変えたいときは、各HTMLファイルの該当する文字を書き換えて保存するだけです。

## 数字を差し替えるとき（トップ「いま動いている数字」）

`index.html` の数字は1か所ではありません。変えるときは次を全部そろえます。

- 大きい数字：`data-count="207"` の値と、中の `207`、すぐ前の `<span class="sr-only">207件</span>`（読み上げ用）
- 口コミの棒：`vb-val` の数字（160・207）と、棒の長さ `--w`（160÷207＝77.3%、残り22.7%）、`+47`
- 評価の星：`4.8` のとき塗る幅は `--w:95.6%`（星4つと5つ目の8割）
- 下の注記の文（日付・件数）
